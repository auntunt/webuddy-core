# 财务审计流程SOP

中小企业年度财务审计标准作业流程

## 环节1：审计准备

- 目的：确认审计范围与独立性，拿到完整账套
- 产物：审计业务约定书、审计计划

### 1.1 业务约定书必须双方签署

判据类型：auto

严格度：block

提示：检查底稿目录下是否有已签署的业务约定书，未签约不得开展审计

### 1.2 独立性声明已签署

判据类型：auto

严格度：block

提示：检查独立性声明文件中每个项目组成员是否都有签署日期

### 1.3 账套完整性确认

判据类型：human

严格度：block

提问：拿到的账套是否覆盖完整会计期间？总账、明细账、凭证是否齐全？

需要凭据：账套起止日期、凭证起止号、移交人签字

提示：必须确认账套的完整性才能开始审计

## 环节2：实质性测试

- 目的：对重大科目取得充分适当的审计证据
- 产物：科目审定表、抽样底稿

### 2.1 重大科目全覆盖

判据类型：auto

严格度：warn

提示：检查测试底稿目录下每个重大科目是否都有对应的底稿文件

### 2.2 银行存款函证已回函

判据类型：auto

严格度：warn

提示：检查函证目录下每份发函是否都有对应的回函

### 2.3 存货监盘记录

判据类型：human

严格度：warn

提问：是否实施了存货监盘？监盘日期、监盘人、抽盘品种数各是多少？

需要凭据：监盘日期、监盘人签字、抽盘品种数、差异处理说明

提示：存货监盘是实质性程序，必须留下记录

## 环节3：审计报告

- 目的：形成审计结论并出具报告
- 产物：审计报告、管理建议书

### 3.1 未更正错报汇总表完整

判据类型：auto

严格度：warn

提示：检查未更正错报汇总表中每条错报是否都有金额和影响科目

### 3.2 报告意见类型不得与底稿矛盾

判据类型：auto

严格度：block

提示：检查审计报告的意见类型是否与未更正错报汇总表的重要性水平结论一致

### 3.3 项目合伙人复核签字

判据类型：human

严格度：block

提问：项目合伙人是否已复核全部底稿并签字？复核发现了哪些问题？

需要凭据：合伙人姓名、复核日期、复核意见条数

提示：合伙人复核是质量控制的最后一道关卡
