## 实体一 领料单

| 字段 | 类型 | 必填 | 谁填 | 什么时候填 | 说明 |
|---|---|---|---|---|---|
| 单号 | 文本 | 是 | 系统 | 创建时 | 按日期加流水号 |
| 班组 | 选择 | 是 | 班组长 | 创建时 | 一班/二班/三班 |
| 领料日期 | 日期 | 是 | 班组长 | 创建时 | 默认当天 |
| 提交人 | 文本 | 是 | 系统 | 提交时 | 记登录账号 |
| 状态 | 选择 | 是 | 系统 | 流转时 | 见状态机 |
| 备注 | 长文本 | 否 | 班组长 | 创建时 |  |
| 作废原因 | 长文本 | 否 | 车间主任 | 作废时 |  |

## 实体二 领料明细

| 字段 | 类型 | 必填 | 谁填 | 什么时候填 | 说明 |
|---|---|---|---|---|---|
| 所属单号 | 文本 | 是 | 系统 | 创建时 | 关联领料单 |
| 物料名称 | 选择 | 是 | 班组长 | 创建时 | 从物料表选 |
| 数量 | 数字 | 是 | 班组长 | 创建时 | 大于 0 |
| 单位 | 文本 | 是 | 系统 | 创建时 | 跟随物料 |

## 实体三 物料

| 字段 | 类型 | 必填 | 谁填 | 什么时候填 | 说明 |
|---|---|---|---|---|---|
| 物料名称 | 文本 | 是 | 车间办事员 | 建档时 | 唯一 |
| 单位 | 文本 | 是 | 车间办事员 | 建档时 | 个/kg/米 |
| 是否停用 | 是否 | 是 | 车间办事员 | 停用时 | 停用后不出现在下拉里 |

## 实体关系

- 领料单 一对多 领料明细（一张单至少一条明细）
- 物料 一对多 领料明细（一种物料可出现在多张单里）
