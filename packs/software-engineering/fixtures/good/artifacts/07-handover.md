## 部署方式

在服务器上执行 `npm run deploy`。脚本会拉代码、装依赖、跑迁移、重启服务。
首次部署要先复制 `.env.example` 为 `.env` 并填 SESSION_SECRET。

换人部署验证：2026-07-29 由 IT 部张工按本文件独立完成一次全新部署，
过程中没有问开发者任何问题，部署后 6 个账号全部能登录，签字确认。

## 备份与恢复

备份：`npm run backup`，每天凌晨 2 点由 crontab 触发，写到 /backup 目录，保留 30 天。

恢复：`npm run rollback` 回滚代码；数据恢复是把 /backup 下的 db 文件拷回 data/ 目录再重启。

恢复演练：2026-07-29 做过一次完整演练。步骤是先删掉 data/app.db，再从 7-28 的备份恢复，
重启后核对最后一张单据（一班 7-28 的领料单，6 条明细）内容完全一致，
从发现故障到恢复可用耗时 8 分钟。张工独立操作，开发者未介入。
